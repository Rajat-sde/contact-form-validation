# DevForm - Interactive Contact Form with Validation

A lightweight, modern, glassmorphic contact form featuring client-side JavaScript validation, real-time input clearing, and user feedback banners.

## 🚀 Features
* **Client-side Validation**: Validates required fields, min-length limits, and email format via Regex.
* **Instant UI Feedback**: Highlights invalid fields in red and displays specific error messages beneath inputs.
* **UX Enhancements**: Automatically clears error states as the user types.
* **Responsive Design**: Mobile-first glassmorphism layout optimized for all screen sizes.

## 🛠️ Tech Stack
* **HTML5**: Semantic tags (`<main>`, `<header>`, `<form>`, `<label>`)
* **CSS3**: Flexbox, CSS Variables, Glassmorphism backdrop filters
* **JavaScript (ES6+)**: DOM Manipulation, Event Listeners, Regex Validation
